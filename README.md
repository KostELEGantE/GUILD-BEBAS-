# SYNDICATE Guild · Party Manager

Situs party manager untuk guild SYNDICATE (Ragnarok). Kode sumber sama dengan BEBAS
(branch `main`, folder `app/`), dibangun dengan `__GUILD__=syndicate`.

- Database: Supabase project `syndicate-guild` (terpisah dari BEBAS)
- Hosting: Cloudflare Pages, production branch `syndicate`
